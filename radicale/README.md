# 日历通讯录（Radicale）

把家里人的手机日历和通讯录同步到自己家：手机自带的日历、联系人应用直接连上就能用，数据存在自己家，
不经过 iCloud、Google 这类外面的账号。像 iCloud 日历一样用，只是服务器换成自己的。

Radicale 是一个开源的日历、通讯录同步服务（CalDAV/CardDAV），本插件用它的官方镜像。

## 能干什么

- 网页上建日历、通讯录，导入导出，地址是插件详情里的“打开”。
- 手机自带的日历、联系人自动和家里同步：加一条日程，全家连上的设备都能看到自己名下的那份。
- 家里每个人有自己的账号，各看各的，互不干扰。

## 第一次使用

装好后打开插件网页就是管理页：建一个日历或通讯录，往里加日程和联系人。不需要再注册或登录，
打开时用的就是云吞的账号。

## 手机怎么连

1. 在云吞的插件详情里打开“在局域网开放”，会显示地址、账号和密码。
2. 按手机类型填一次，之后全自动同步：
   - **iPhone/iPad**：设置 → 日历（或通讯录）→ 账户 → 添加账户 → 其他 → 添加 CalDAV 账户，
     服务器、用户名、密码照详情里填。日历和通讯录共用这一个账户。
   - **Android**：安装开源同步应用 [DAVx⁵](https://www.davx5.com/)，添加账号，地址、用户名、密码照详情里填，
     然后按提示开启系统日历、联系人的同步。
   - **电脑（Thunderbird）**：日历 → 新建日历 → 网络 → CalDAV，地址照详情里填，用户名密码同。

网页上登录的用户和手机上填的账号是同一个用户名，网页上建的日历手机上看得到。

## 家人怎么用

网页：家人在云吞里打开这个插件，就是他们自己的账号，各看各的日历。

手机同步：只有装插件时这个账号（主人）预置了同步密码；家里其他人的手机账号本插件没法预先建好
（云吞没有把家人名单给插件），需要等底座支持。知道谁要用的替代办法：暂时用主人的账号，或者等后续版本。

## 数据存在哪、怎么备份

- 日历和通讯录是普通文件（`.ics`、`.vcf`），存在插件数据目录的 `collections/` 里。
- 备份：备份整个插件数据目录即可；恢复后日历通讯录原样回来。
- 卸载时选择保留数据，重新装回来数据还在。

## 已知限制

- **只在家里网络同步**：手机同步走的是局域网直连，不在家时手机不更新；出门在外想看，需要家里有
  人开着设备或等云吞支持外网入口。网页管理页不受影响，走云吞的入口。
- 手机直连是明文 HTTP：局域网里传输的账号密码不加密，家庭网络里可以接受；不能接受的别开“在局域网开放”。
- 日历共享（把我的日历给别人看）暂未配置，每人只能看自己的。
- 密码在插件详情里显示，是这台服务器随机生成的；在应用里改密码后详情里显示的不会跟着变。
