# Halo 博客（Halo）

在家里写博客：像写日记一样把文章、游记和照片发成自己的网站，家人打开就能看。

- [Halo](https://www.halo.run) 是国内最流行的开源博客和建站工具之一。这个插件用的是 Halo 上游官方镜像（GPL-3.0），单容器加内置数据库，装好就能用。

## 怎么用

1. 装好后打开插件网页，就是你的博客。管理员账号已经建好：用户名是你的云吞用户名（带下划线时写作连字符），密码在 App 的插件详情页「管理员密码」里查看。
2. 写文章：浏览器打开博客地址加 `/console` 进后台（也可以直接打开 `https://<博客地址>/console`），用上面的账号登录，在「文章」里写和发布。
3. 家里人看文章不需要账号，打开博客就能读；让他们在各自设备上打开插件网页即可。想给谁写或管理的权限，在后台的「用户」里建账号。
4. 站点标题、主题这些在后台的「系统 - 设置」里改。

Bot 也能帮你：跟它说"帮我看看博客里有哪些文章""把这段发成一篇博客"。

## 数据存在哪、怎么备份

- 全部数据（文章、图片、数据库、主题）都在插件的数据目录里（数据目录下的 `halo2` 文件夹）。
- 备份：把整个插件数据目录拷走即可；Halo 后台的「备份」功能也能用，恢复时按它的说明来。删掉插件并勾选删除数据时，这些内容会一起删除。
- 升级插件、不删数据重装都不影响已有文章。

## 已知限制

- **博客只有家里人能看**：读者必须能通过你家服务器的入口访问，没法把文章公开给互联网上的陌生人。
- **Halo 应用市场用不了**：主题和插件市场需要访问外网，这个插件没有申请出网。Bot 用的「MCP Server」是 Halo 自带的，不用装；想要别的主题或插件，需要给插件开出网权限后在后台的市场里装（装什么自己把关）。
- 使用内置数据库，官方文档提醒数据文件要避免不当中断；重要内容定期备份。
