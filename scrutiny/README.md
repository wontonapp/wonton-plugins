# 硬盘体检（Scrutiny）

给家里的硬盘定期做体检：每天读一次硬盘自己记录的健康数据（坏道、温度、通电时间），网页里每块盘一张仪表盘，指标变差时标出来，趁硬盘彻底坏掉之前换掉。

## 用法

安装时勾选要监控的盘。核心不要求一定选，一块不选也装得上，但网页里没有盘，要在 App 里改授权补上。装着系统的盘也列出来、默认不勾；只在测试机上才建议勾它。装好后打开插件网页看仪表盘和详情，页面在云吞网关的登录后面，应用自己没有账号。

- 只列物理整盘和 NVMe，不列分区、逻辑卷和循环文件。挂在 USB 硬盘盒或 RAID 卡后面的盘可能认不出，认不出就选不了。
- 勾 NVMe 要多确认一次：读它的健康数据需要更大权限。选过 NVMe 的插件升级时要按最高风险再确认一次。
- 盘只读交给插件，健康数据只读不改，不碰盘上的文件。
- collector 在容器启动时跑一次，之后每天跑一次；拔掉盘以后插件标为异常，插回来要在 App 里重启插件。
- 网页只经云吞的通道访问，不开局域网端口。插件没有设置页，发通知（邮件、webhook）要在容器里改配置文件。

## 隧道端口

清单把 8080 列进 `tunnel.ports`，映射到已配对设备的本机、和插件端口同号。应用没有登录，映射开着的期间，设备本机上的任何程序都能直接打开它：同机上别的应用不受保护，靠的是网页本来就不认身份。

## 权限

`devices.disk`（很高；勾了 NVMe 时最高）：选中的整块盘只读挂进容器，能读到盘上的全部数据。核心同时给 `SYS_RAWIO`，勾 NVMe 时还给 `SYS_ADMIN`，读健康数据要用；都不写在清单里。

宿主没有认得出的物理盘时，安装页里没有可勾的盘；照常装得上，只是没有仪表盘。
