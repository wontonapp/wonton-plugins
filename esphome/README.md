# 自制设备固件（ESPHome）

用网页给 ESP32、ESP8266 这些小板子写固件：描述设备是什么、接了什么，ESPHome 生成固件刷进去，
设备就能接入 Home Assistant 这类智能家居。

- **装好就能用**：打开插件网页，用详情页里的密码登录。
- **第一次刷机**：在电脑浏览器的网页安装器里完成，之后改配置都能无线更新，不用接线。
- **让助手帮忙**：设备配置可以让家里的助手代写、验证和编译（走上游自带的 MCP 接口）。

## 需要的权限

- **宿主网络（`network.host`）**：发现局域网里的设备和无线刷机（OTA）要靠 mDNS，这是上游官方
  部署的方式。网页只监听本机回环地址，由云吞核心中继接入网关，局域网里绕不过登录。
- **USB 设备（可选，默认关）**：给第一次刷机用。关着时只能无线刷机，第一次刷机用电脑浏览器里的
  网页安装器。
- 编译固件要下载 PlatformIO 工具链（首次编译下载量较大），经宿主网络直连，不走平台的出网代理。

## 数据

设备配置（YAML）和编译缓存在插件数据目录的 `config/` 下，重装不丢；卸载时选删除数据才会清掉。
