# 家庭记账（ezBookkeeping）

把 [ezBookkeeping](https://github.com/mayswind/ezbookkeeping)（MIT）包成云吞插件：记花销和收入的个人账本，
能导入支付宝、微信的账单，手机上好用。账目存在自己家里。

## 登录

用应用自己的账号密码登录（`sso: none`）。装好插件时，云吞已经按你的云吞用户名预建好账本账号：
用户名就是云吞用户名，初始密码在云吞的插件设置里查看（是核心生成的随机密码），登录后可以在应用里改掉。
账本默认就是中文和人民币，不用再设置。

- 家人各自打开注册页注册自己的账号，各记各的账，数据互相独立；给好友开放插件后同理。
- 助手要能签发令牌，所以自助注册保持打开，登录和注册都是应用自己的页面。

## 助手（MCP）

上游自带 MCP（Streamable HTTP，`/mcp`），插件把它接进云吞的工具总线，共 8 个工具（记账、删账、查账、查类别/标签/账户/汇率）。
装好就能用：插件的一次性服务在建号后立即替主人签发 MCP 令牌，交给核心保管，总线经 `Authorization: Bearer`
带给应用；助手看到的是你的账本。令牌默认不过期，存在插件数据目录里，重装后还在；你在应用「设置 → 安全」
里吊销它之后，重建容器（升级、重装）时会用初始密码重新签发。

- 上游的 MCP 令牌签发强制过账号密码确认（应用设计），签发用的是预建账号和核心生成的初始密码；
  改掉应用密码并吊销令牌后，插件续签不了（重建容器会如实失败），把密码改回去即可恢复。
- 上游的工具都没有标 `readOnlyHint`（上游没实现 MCP 注解），所以助手每次调用都会发确认卡片。

## 数据

都在 `${WONTON_APP_DATA}` 下：`data/`（SQLite 库）、`storage/`（头像、小票图片）、`mcp/`（MCP 令牌，核心也收存一份）。
日志只走 stdout。卸载 `--purge` 删干净。

## 出网与模型

- `network.egress`：汇率数据源（默认欧洲央行）在应用里拉取；地图瓦片由浏览器直接取。
- `models`：AI 记账（文字/小票识别）走云吞的模型网关（OpenAI 兼容接口）。网关没接上时这些配置为空，
  应用里的 AI 功能如实不可用；已连接时用网关的默认模型。

## 已知限制

- 上游是按"每人一个账本"设计的，没有家庭共用一本账的功能；家人各自注册各自记。
- 助手的每次调用要确认（上游没标 `readOnlyHint`，见上）。
- 预建账号绕过了应用的注册表单，家人注册的账号仍要在「我的 → 个人资料」里把默认货币改成人民币。
