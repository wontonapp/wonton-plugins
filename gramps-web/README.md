# 云吞插件：家谱（Gramps Web）

把家里的家谱搬到网上，亲戚用手机或电脑打开就能一起补充：加人、写生平、传老照片。上游是
[Gramps Web](https://www.grampsweb.org)（AGPL-3.0），本仓库把它包成云吞插件：官方镜像、
云吞登录、数据放在插件数据目录。

登录用云吞的账号（核心的身份提供方，OIDC）：打开网页自动登录，本地用户名密码登录和注册都关掉了。
主人进应用是管理员；家人和被分享进来的亲戚是可以编辑家谱的角色（在应用里可以逐个调整）。

## 数据在哪

全部在插件数据目录（`.wonton/data/apps/<slug>/` 或宿主上 `WONTON_APP_DATA`）下：

| 子目录 | 内容 |
| --- | --- |
| `grampsdb/` | 家谱数据库（人、家庭、事件、备注） |
| `media/` | 上传的照片和文件 |
| `users/` | 用户库 |
| `indexdir/` | 全文搜索索引 |
| `cache/`、`thumbnail_cache/` | 导出、报表和缩略图缓存（可随时清空重建） |

卸载时选"删除数据"会清掉以上全部；只保留数据卸载，重装后家谱原样还在。

## 要外网的地方

- AI 问答经云吞的模型网关，不用填密钥；默认关闭，主人在应用的"用户管理"里按角色开启后可用。
  没接上模型网关时，聊天会报"AI 模型未配置"，其余功能不受影响。
- 地名页面的地图底图要从网上取，没有外网时地图空白，家谱本身不受影响。
- 插件没有申请出网权限：家谱数据只存在这台服务器上。

## 和云吞家人名单的关系

- 家人打开这个应用（或在应用里开放给家人后）：第一次登录时应用自动建账号，角色是"编辑"。
- 亲戚不是家人：用云吞的好友分享把这个应用分享给对方，对方用自己已有的云吞账号登录，
  应用同样自动建"编辑"账号；想给亲戚更低的权限，在应用的"设置 → 管理 → 用户管理"里改。
- 收回分享不会删掉应用里已建的账号，要删在应用的用户管理里删。

## 已知限制

- 应用里不要改树的名字：插件按固定的树名启动，改名后重启会出现一棵新的空树（旧数据还在数据目录里）。
- 任务队列（Valkey）不持久化：卸载重装排队中的导出、缩略图任务会丢，家谱数据不受影响。
- 上游应用以 root 跑官方镜像，数据文件归 root；插件数据目录属主按云吞规范交给用户的 PUID/PGID。
