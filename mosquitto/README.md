# 设备消息中心（Mosquitto）

家里的智能设备和其他插件互传消息都经过它：像一台家里自己的邮局，设备把状态寄进来，软件把指令寄回去。
Zigbee2MQTT、ESPHome、Home Assistant、Node-RED 这类软件和 ESP 开发板、网关等硬件都连它。

装好就能用，没有自己的网页——它服务的是设备和其他插件。要连家里的设备：在插件详情里打开“在局域网开放”，
把显示的地址（`mqtt://<主机>:1883`）和账号填进设备。账号是主人的用户名，口令由云吞生成；用户在应用里改不了，
插件重建后口令不变（口令文件在数据目录里，重装保留数据时账号原样保留）。

## 给插件作者

其他插件和设备用 MQTT 账号连 1883；地址、账号和口令在本插件详情页（打开“在局域网开放”后显示）。

## 权限

- `network.lan`：在局域网开放 1883，给智能设备直连。默认不开，在插件详情里打开。
- `owner.identity`：主人的用户名用来建局域网账号。
